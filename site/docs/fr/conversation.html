Conversation et terminal

Chaque session fait tourner son agent dans un vrai terminal. La vue conversation lit ce qu’écrit l’agent et l’affiche comme un chat : les messages en entier, le reste replié sous un titre qui résume ce qu’il a fait.

Deux vues d’une même session

Le sélecteur Conversation | Terminal de la barre d’outils, ou Présentation › Afficher le terminal (⌥⌘T), passe de l’une à l’autre. Les deux restent actives : le passage est instantané et chacune garde sa position. Chaque session retient la vue dans laquelle vous l’avez laissée ; les nouvelles sessions s’ouvrent dans celle choisie dans Réglages › Général.

Le terminal fait toujours foi : la conversation est lue à partir de ce qu’écrit l’agent.

Le terminal est l’interface de l’agent lui-même, intacte : tout ce que vous pouvez faire dans claude ou codex dans un terminal, vous pouvez le faire ici. La barre d’état en dessous indique si le processus tourne, avec Arrêter ou Relancer, et le bouton des terminaux annexes.

Lire une conversation

  • Les messages — les vôtres et ceux de l’agent — s’affichent en entier, avec le Markdown, les tableaux et le code.
  • Les appels d’outils sont repliés sous un titre : « 2 fichiers lus », « Recherche de VAT_RATE », « Lancer la suite de tests — 13 tests réussis ». Les appels consécutifs de même nature sont regroupés ; l’état le plus grave s’affiche sur le groupe. Cliquez pour déplier : une modification de fichier montre son diff, une commande sa sortie.
  • Le raisonnement, quand l’agent le partage, est une ligne repliée.
  • Les sous-agents lancés par l’agent apparaissent sous forme de blocs avec leur mission, leur activité et leur résultat ; un bandeau liste ceux qui tournent encore.
  • Les images générées par l’agent s’affichent sur place.

Quand vous remontez, une pastille nouveaux messages vous ramène à la fin. Édition › Copier en Markdown (⌥⇧⌘C) copie la sélection avec sa mise en forme. Ce qui est replié ou déplié se règle dans Réglages › Conversation › Détails techniques.

La conversation est lue dans les fichiers de transcript qu’écrivent Claude Code et Codex, et gardée en mémoire seulement. Vibe Manager ne l’écrit nulle part, ne la journalise pas et ne l’envoie jamais. Les liens se limitent à http, https et mailto, et aucune image distante n’est chargée.

Écrire à l’agent

La zone de saisie en bas écrit dans le terminal de l’agent comme si vous tapiez vous-même.

  • Return envoie, ⇧Return ajoute une ligne.
  • ↑ et ↓ sur la première ou la dernière ligne rappellent les messages déjà envoyés.
  • Un message saisi pendant que l’agent travaille est envoyé à la fin de son tour.
  • Esc interrompt l’agent, comme la pastille Arrêter affichée pendant un tour.
  • / en début de message ouvre la liste des skills et des commandes de l’agent, que la CLI elle-même fournit. La saisie la filtre ; ↑ ↓ choisissent, ⇥ ou un clic insère, Esc ferme. Return complète un nom commencé, et envoie tel quel un nom tapé en entier. Une commande qui répond par un panneau, comme /mcp ou /model, montre le vrai terminal au-dessus de la zone de saisie le temps de s’en servir.
  • Un message qui commence par ! est une commande shell, exécutée par le mode shell de l’agent lui-même ; la zone de saisie prend la couleur d’avertissement. Tapez \! pour envoyer un message qui commence par un point d’exclamation.

Tant que l’agent attend une réponse dans son terminal — une autorisation, une question —, la zone de saisie est fermée et la demande s’affiche à sa place : voir Répondre à vos agents.

Joindre des fichiers

Déposez des fichiers sur la conversation, cliquez sur + dans la zone de saisie ou choisissez Session › Joindre des fichiers… (⌘O) : ils deviennent des pastilles dans la zone de saisie et sont envoyés sous forme de chemins avec votre message. Déposé sur le terminal, le chemin d’un fichier est saisi, échappé comme le fait Terminal, sans appuyer sur Retour. Vous pouvez aussi déposer des fichiers sur la ligne d’une session dans la barre latérale.

Les pièces jointes d’un message envoyé restent visibles sous son texte : miniature d’une image, première page d’un PDF, premières lignes d’un fichier texte, petit lecteur pour un son. Un clic les ouvre dans Coup d’œil (← → passent d’une pièce à l’autre) ; un clic droit propose Ouvrir, Afficher dans le Finder, Copier et Ouvrir dans la vue web. Un programme ou un script ne s’ouvre jamais d’ici.
