Gabarits de session

Un gabarit de session prépare ce qu’il faut pour lancer une session : un prompt à champs — Review {{url}} —, et au besoin le dossier, le nom et le badge. Puis un formulaire, un aperçu exact, et une session nommée d’après ce que vous avez saisi.

Démarrer une session à partir d’un gabarit

Choisissez un gabarit en haut du brouillon de nouvelle session, ou passez directement par Fichier › Nouvelle session à partir de ; ⇧⌘N ouvre le premier. Chaque champ devient une commande de formulaire ; un champ obligatoire empêche de créer la session tant qu’il n’est pas rempli. La zone de saisie montre le prompt exactement tel que l’agent le recevra.

Le gabarit propose le dossier, le nom et le badge ; la zone de saisie montre le prompt exact.

La session conserve le texte obtenu, avec le nom et la révision du gabarit : modifier le gabarit plus tard ne change rien de ce qui a déjà été créé, pas même ce qu’envoie Relancer.

Écrire un gabarit

Les gabarits se modifient dans Réglages › Gabarits, accessible aussi par Fichier › Gérer les gabarits de session….

L’éditeur de gabarits, avec une valeur d’essai par champ.
À quoi sert-il ?
Le nom du gabarit, tel qu’il apparaît dans les menus.
Nom de la session
Facultatif, avec les mêmes champs : Review !{{url|/merge_requests\/(\d+)/}}. Il nomme la session jusqu’à ce que vous lui donniez un nom à vous.
Dossier
Facultatif : le dossier de travail proposé avec le gabarit. Écrit avec ~, il désigne le même dossier sur un autre Mac.
Apparence
Facultatif : le symbole et la couleur donnés à ses sessions.
Prompt
Le texte, avec ses champs. Le tableau en dessous définit pour chaque champ son libellé, son indication, s’il est obligatoire et s’il accepte plusieurs lignes.

La colonne Essayer prend une valeur par champ et montre ce que chaque motif en garde ; l’aperçu en dessous utilise les mêmes valeurs. Enregistrer ou Annuler les modifications quand vous avez terminé. Le menu ⋯ duplique, déplace, supprime, importe et exporte les gabarits, et Ajouter les exemples en ajoute quelques-uns pour démarrer.

Syntaxe

ÉcritSignifie
{{url}}Un champ obligatoire nommé url. {{ url }} et {{URL}} désignent le même champ.
{{focus?}}Un champ facultatif. Laissé vide, il n’ajoute rien.
{{url|/merge_requests\/(\d+)/}}Une partie seulement de la valeur : ce que trouve l’expression régulière, ou son premier groupe — 1315 dans …/merge_requests/1315/diffs.
\{{Deux accolades littérales : \{{url}} donne le texte {{url}}.

Un nom de champ commence par une lettre et contient des lettres, des chiffres, - et _. Tout le reste entre doubles accolades — {{payload.url}}, {{#each}} — reste du texte, car les prompts regorgent de code qui utilise les mêmes accolades ; l’éditeur le souligne. Un même champ utilisé deux fois n’est demandé qu’une fois. Un gabarit compte au plus 20 champs et 16 Ko de texte.

Un motif qui ne trouve rien n’ajoute rien : le formulaire le signale sous le champ, et la session peut quand même être créée. {{url|/(?:merge_requests|pull)\/(\d+)/}} donne aussi bien le numéro d’une merge request GitLab que celui d’une pull request GitHub.

Ce que reçoit l’agent

  • Une valeur est insérée telle que saisie, et n’est jamais relue : une valeur contenant {{x}} reste ce texte.
  • Rien n’est mis entre guillemets : le prompt parvient à l’agent comme un argument unique, sans shell intermédiaire, si bien que $, les guillemets et les backticks arrivent intacts.
  • Un champ d’une ligne perd ses espaces de début et de fin ; les caractères de contrôle collés depuis un terminal en couleur sont supprimés.

Partager des gabarits

Exporter… écrit un fichier JSON ; Importer…, ou le dépôt d’un fichier sur la fenêtre, en lit un et montre d’abord quels gabarits sont nouveaux, identiques ou modifiés. Un gabarit modifié est conservé à côté du vôtre, sauf si vous choisissez Remplacer. Le format du fichier est documenté dans docs/prompt-templates.md.
