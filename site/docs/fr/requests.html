Répondre à vos agents

Un agent d’une session en arrière-plan qui s’arrête sur une autorisation ou une question n’attend pas que vous ouvriez sa session : sa demande vient à vous.

Ce qu’un agent peut demander

  • Une autorisation : exécuter une commande shell, modifier un fichier, charger une adresse. Répondez Autoriser, Toujours (quand l’agent propose de s’en souvenir) ou Refuser.
  • Une question, avec des options à choisir ou Autre réponse… pour saisir la vôtre ; Envoyer les réponses quand il y en a plusieurs.
  • Un plan à valider (Claude Code) : Valider, modifications acceptées d’office, Valider, chaque modification à approuver ou Rejeter.

Dans la session affichée, la demande apparaît dans la conversation, à la place de la zone de saisie. Ailleurs, elle rejoint la palette.

Refuser met aussi fin au tour de l’agent : il attend alors votre prochain message. C’est ainsi que fonctionnent les CLI : refuser revient à appuyer sur Échap.

La palette Demandes en attente

La palette se trouve en bas de la barre latérale et liste les demandes de toutes les autres sessions, de la plus ancienne à la plus récente, quelle que soit leur colonne. Chaque carte indique quelle session demande, avec quel agent et dans quel dossier, et montre la commande ou la question en entier ; Tout afficher déplie une demande longue.

Deux sessions en attente d’autorisation, sans quitter la session affichée.
  • Cliquez sur Autoriser ou Refuser : la réponse est saisie dans le terminal de cette session, exactement comme vous l’auriez fait, et votre propre session garde le clavier.
  • Le bouton flèche, ou ⌘Return, ouvre la session de la demande.
  • ⌥⌘P donne le clavier à la palette : ↑ ↓ pour passer d’une demande à l’autre, Tab puis Space sur une réponse, Esc pour revenir.
  • L’en-tête replie la palette en un simple compteur.

Une demande dont les détails ont été tronqués, ou qu’on ne peut pas distinguer d’une autre, ne peut recevoir de réponse que dans son terminal : la carte le signale et propose Répondre dans le terminal.

Quand Vibe Manager est en arrière-plan

Inutile de garder Vibe Manager au premier plan pour savoir qu’un agent attend. Choisissez, dans Réglages › Demandes › Signalement :

Les notifications
Une notification système pour chaque demande, qui montre soit le type de demande, soit la commande elle-même. Une autorisation peut être accordée ou refusée directement depuis la notification. L’icône du Dock compte les demandes en attente.
Le panneau flottant
Un avatar, dans une bulle au-dessus de toutes les autres apps et sur tous les Spaces, qui présente les demandes une à une et vous permet d’y répondre là où vous êtes. Il ne prend jamais le clavier de lui-même : appuyez sur ⌃⌥⌘P pour lui prêter le clavier (← → pour passer d’une demande à l’autre, ⌘Return pour ouvrir la session, Esc pour rendre le clavier). Glissez-le où vous voulez ; sa position est retenue pour chaque écran. Tant qu’il est actif, aucune notification n’est publiée, puisque la bulle le dit déjà.

L’avatar peut être celui par défaut, un avatar que vous importez, ou un avatar qu’un agent dessine d’après votre description : voir Thèmes et avatars.
