Créer une session

Une nouvelle session commence comme un brouillon dans la zone principale. Rien ne s’exécute avant que vous l’envoyiez.

Ouvrir un brouillon

Appuyez sur ⌘N, choisissez Fichier › Nouvelle session ou cliquez sur + dans la barre d’outils. Le brouillon apparaît en haut de la barre latérale et occupe le centre de la fenêtre. Pour partir d’un dossier que vous utilisez déjà, faites un clic droit sur un en-tête de groupe dans la barre latérale groupée et choisissez Nouvelle session dans ce dossier.

Un brouillon : les options en haut, le premier message en bas.

Les options

Badge et titre
Le badge à gauche du titre ouvre un choix de symboles et de couleurs ; une session dans un dossier doté d’une icône d’app, d’un favicon ou d’un logo le porte par défaut. Le titre est facultatif : laissé vide, il est tiré du premier message à l’envoi.
Gabarit de prompt
Aucun — prompt libre, ou l’un de vos gabarits de prompt. Un gabarit peut proposer le dossier, le nom et le badge ; ses champs apparaissent juste en dessous.
Dossier de travail
Le dossier dans lequel l’agent travaille. Vos dossiers récents sont proposés sous forme de cartes (les trois derniers, puis Afficher … de plus) ; un clic droit sur l’un d’eux le retire de la liste ou l’affiche dans le Finder. Choisir… ouvre n’importe quel autre dossier. L’agent démarre dans ce dossier ; il peut créer des branches et des worktrees de lui-même, et l’inspecteur les signale.
Agent
Une carte par agent trouvé sur ce Mac, avec son état. Un agent absent, trop ancien ou déconnecté le signale ; corrigez-le et cliquez sur Relancer la détection.
Modèle
Modèle par défaut de l’agent, ou l’un des modèles que liste la CLI de l’agent. Gardez le modèle par défaut pour utiliser celui configuré dans la CLI.
Plus d’options › Ticket
Facultatif : l’URL d’un ticket ou un numéro comme #142. Il désigne le ticket de la session, l’ouvre dans la vue web et permet à Ouvrir rapidement de retrouver la session grâce à lui. Laissé vide, il est rempli plus tard par une branche nommée d’après un ticket.

Le premier message

Décrivez la tâche dans la zone de saisie en bas : c’est le premier message de l’agent. Avec un gabarit, la zone de saisie montre le prompt exactement tel que l’agent le recevra ; Modifier comme texte permet de le retoucher à la main.

  • Return ou le bouton flèche crée et lance la session (⌘Return fonctionne depuis n’importe où dans le brouillon).
  • ⇧Return ajoute une ligne.
  • ⌥Return ou Ajouter à À faire crée la session sans la démarrer : elle attend dans la colonne À faire jusqu’à ce que vous la démarriez avec Session › Démarrer la session (⌃⌘R).
  • Esc met le brouillon de côté ; Abandonner le supprime.

Déposez des fichiers n’importe où sur le brouillon, ou cliquez sur +, pour les joindre au premier message.

Sans prompt, l’agent démarre sans rien à faire : pratique pour ouvrir une CLI dans un dossier et lui écrire vous-même.

Renommer et changer l’icône

Le nom et le badge d’une session peuvent changer à tout moment : Session › Renommer… (⌃⌘E) ou un double-clic sur sa ligne, et Session › Changer l’icône… (⌃⌘I) ou un double-clic sur son badge. ⌘Z annule l’un comme l’autre. Les symboles et couleurs proposés se règlent dans Réglages › Badges.

Ce qui se passe à l’envoi

La session est d’abord enregistrée, puis affichée, puis son agent est lancé dans un terminal dédié. Si le lancement échoue, la session est conservée avec tout ce que vous avez saisi, et Relancer fait une nouvelle tentative. La session passe En cours, et l’activité de l’agent s’affiche désormais sur sa ligne.
