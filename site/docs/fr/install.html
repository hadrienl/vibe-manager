Installer Vibe Manager

Téléchargez l’image disque, glissez l’app dans Applications, et vérifiez qu’au moins un agent est installé et connecté.

Configuration requise

  • macOS 14 Sonoma ou ultérieur, sur Apple silicon ou Intel.
  • Au moins un agent de code, installé et connecté :
    AgentCommandeVersion minimaleConnexion
    Claude Codeclaude2.1.0claude auth login
    Codex CLIcodex0.153.0codex login

Vibe Manager utilise vos agents tels quels, avec votre propre compte et votre quota. Il ne demande jamais de clé d’API.

Télécharger et installer

  1. Téléchargez le dernier .dmg depuis la page d’accueil ou depuis GitHub Releases.
  2. Ouvrez-le et glissez Vibe Manager dans Applications.
  3. Lancez-le depuis Applications. L’app est signée avec un Developer ID et notarisée par Apple : macOS l’ouvre sans avertissement.

Les mises à jour sont ensuite proposées par l’app elle-même : voir Réglages › Mises à jour.

Comment les agents sont trouvés

Au lancement, et chaque fois que vous cliquez sur Relancer la détection, Vibe Manager cherche claude et codex aux emplacements habituels — /opt/homebrew/bin, /usr/local/bin, ~/.local/bin, ~/.bun/bin, ~/.npm-global/bin, ~/.volta/bin, les shims d’asdf et de mise, ~/.claude/local, ~/.codex/bin… — puis dans votre PATH, et enfin dans le PATH de votre shell de connexion. Une version native est préférée à une version qui tourne sous Rosetta.

Quand un agent est inutilisable, le formulaire de nouvelle session en donne la raison : non installé, non exécutable, trop ancien ou non connecté. Corrigez-le dans un terminal, puis cliquez sur Relancer la détection.

Accès complet au disque

Les agents tournent comme processus enfants de Vibe Manager : quand l’un d’eux lit un dossier protégé — Documents, Bureau, Téléchargements, iCloud Drive —, macOS demande l’autorisation à Vibe Manager. Pour vous éviter une série d’alertes en plein travail, l’app propose une fois, au premier lancement, d’accorder l’Accès complet au disque :

L’étape unique de l’Accès complet au disque.
  1. Cliquez sur Ouvrir Réglages Système : Confidentialité et sécurité › Accès complet au disque s’ouvre.
  2. Activez Vibe Manager.
  3. Revenez dans Vibe Manager.

Plus tard est une réponse tout à fait valable : les dépôts sont rarement dans des dossiers protégés, et rien n’est désactivé. Vous pourrez l’accorder plus tard depuis Réglages › Confidentialité, qui indique aussi si les processus qui font tourner vos agents en disposent déjà.

Les agents gardent l’accès qu’ils avaient à leur démarrage. Si vous accordez l’Accès complet au disque pendant que des agents tournent, Réglages › Confidentialité propose Redémarrer à la fin des agents ou Redémarrer maintenant… pour qu’ils en bénéficient.

Votre première session

Appuyez sur ⌘N, choisissez un dossier de travail, vérifiez l’agent, décrivez la tâche et appuyez sur Return. La page suivante détaille chaque option : Créer une session.
