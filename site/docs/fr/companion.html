Compagnon iPhone (alpha)

Suivez vos sessions depuis l’iPhone et répondez aux demandes de vos agents, même loin du Mac. Le compagnon est en alpha : l’app iPhone se distribue par TestFlight, et il demande un Mac Apple Silicon.

La page Compagnon iPhone des réglages.

Rejoindre la bêta TestFlight

Installer l’alpha

  1. Sur le Mac, ouvrez Réglages › Compagnon iPhone et activez Utiliser Vibe Manager depuis votre iPhone ; l’assistant est livré avec Vibe Manager et désactivé par défaut.
  2. Installer l’alpha… ouvre les instructions pour rejoindre le test TestFlight et installer l’app sur l’iPhone.
  3. Ouvrez l’app sur l’iPhone, avec le même compte iCloud que le Mac : il apparaît dans la liste des iPhone. Retirer… l’en enlève.

Sur un Mac Intel, la page indique que le compagnon n’est pas disponible.

Ce que fait le compagnon

  • La liste de vos sessions, leur statut et ce que fait chaque agent, groupées comme sur le Mac.
  • Des notifications quand un agent a besoin de vous : Autoriser (après Face ID ou le code) ou Refuser sans ouvrir l’app.
  • Les questions, y compris celles qui en posent plusieurs, auxquelles vous répondez depuis l’iPhone.

La vue web

Dans une conversation, le bouton Vue web ouvre la vue web de la session. Elle affiche la page active du Mac et la suit, et le menu des onglets passe d’un onglet du Mac à l’autre. Le sous-titre indique Synchronisée avec le Mac. Le Mac et l’iPhone ne partagent pas de session : chacun a ses propres cookies.

  • Seules vos navigations sont envoyées au Mac, c’est-à-dire une adresse tapée ou un lien touché. Les redirections, les rechargements et les réponses de formulaires restent sur l’iPhone.
  • Sur une page de connexion (GitHub, GitLab, Google, Microsoft, Apple, Okta, Auth0, Keycloak…), la vue se détache d’elle-même : la pastille Non synchronisé apparaît dans la barre d’adresse, et l’iPhone ne suit plus le Mac ni ne lui envoie rien. Elle se rattache seule quand la connexion revient sur une page du site. Touchez la pastille pour la rattacher plus tôt.
  • Désynchroniser détache la vue à la main. Elle reste détachée jusqu’à ce que vous touchiez Non synchronisé ou choisissiez un onglet.
  • Ouvrir dans Safari ouvre la page affichée dans Safari, ou dans l’app que son adresse ouvre, comme GitHub. Il est grisé sur les pages propres au Mac, que seul le Mac peut joindre.

Les passkeys ne fonctionnent pas dans la vue web. Connectez-vous avec un mot de passe, ou ouvrez la page dans Safari.

Sans serveur

Le Mac et l’iPhone se parlent par CloudKit, dans votre iCloud privé : aucun serveur de Vibe Manager entre les deux. Seuls les iPhone dont la clé est publiée dans votre iCloud sont admis.
