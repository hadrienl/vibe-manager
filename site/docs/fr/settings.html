Agents

Une page par agent : Claude Code, Codex. Le point de la barre latérale dit s’il est prêt (vert), utilisable avec quelque chose à régler, trop ancien ou pas connecté (orange), ou introuvable (rouge). La page montre où son outil en ligne de commande a été trouvé et sa version ; Relancer la détection le cherche à nouveau, après une installation ou une mise à jour.

Suivre l’activité de …
Pour un agent qui fait approuver ses hooks, comme Codex. Activé, les hooks signalent quand il travaille, demande ou termine, ce dont la barre latérale et les demandes ont besoin. La première fois, une feuille montre les commandes qu’exécutent les hooks, et vous les approuvez une fois pour toutes. Claude Code n’a pas ce réglage : ses hooks n’ont pas à être approuvés.

Tickets

Quand une nouvelle session désigne un ticket — dans son champ Ticket, son nom ou son prompt —, sa page s’ouvre dans la vue web et, avec Insérer le titre des tickets dans les notes, son titre est ajouté en haut des notes, dans le Format de la ligne de votre choix ({title}, {id}, {url}).

La ligne Résolveurs ouvre leur page. Un résolveur indique quelles adresses sont des tickets : GitHub, GitLab, les merge requests GitLab, Jira Cloud et Linear sont fournis. Ajoutez les vôtres pour un GitLab auto-hébergé, un Jira Server ou un Redmine : un nom, un motif d’adresse avec une capture nommée comme (?<number>[0-9]+), un identifiant comme #{number}, et des motifs de nettoyage du titre. Tester avec une adresse le vérifie. Les résolveurs peuvent être importés et exportés ; voir docs/ticket-resolvers.md.

Confidentialité

Indique si Vibe Manager dispose de l’Accès complet au disque — Accordé, Non accordé, ou Accordé, pas encore effectif —, avec Ouvrir Réglages Système. Les agents héritent de l’accès du processus qui les fait tourner, lequel a pu démarrer avant que vous l’accordiez : Redémarrer à la fin des agents le laisse partir une fois son dernier agent terminé, Redémarrer maintenant… arrête les agents qu’il cite et les reprend. La section Processus par processus apparaît quand ils ne sont pas d’accord.
