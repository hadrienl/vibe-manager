Ouvrir les fichiers modifiés avec
Ce que font Return ou un double-clic sur un fichier de l’inspecteur : Finder (afficher seulement), Application par défaut, l’un des éditeurs trouvés sur ce Mac, ou Autre….
Activité des agents › Suivre l’activité de …
Un interrupteur par agent. Activé, les hooks de l’agent signalent quand il travaille, demande ou termine, ce dont la barre latérale et les demandes ont besoin. La première fois, une feuille montre les commandes qu’exécutent les hooks, et vous les approuvez une fois pour toutes.
Utilisation › Suivre l’utilisation des agents
Enregistre le temps d’exécution et lit les compteurs de jetons pour la fenêtre Utilisation. Effacer les données d’utilisation… efface ce qui a été enregistré, pas les transcripts des agents.
Diagnostics
Exporter les diagnostics… : voir Dépannage.

Confidentialité

Indique si Vibe Manager dispose de l’Accès complet au disque — Accordé, Non accordé, ou Accordé, pas encore effectif —, avec Ouvrir Réglages Système. Les agents héritent de l’accès du processus qui les fait tourner, lequel a pu démarrer avant que vous l’accordiez : Redémarrer à la fin des agents le laisse partir une fois son dernier agent terminé, Redémarrer maintenant… arrête les agents qu’il cite et les reprend. La section Processus par processus apparaît quand ils ne sont pas d’accord.

Terminaux

Conserver l’historique des terminaux annexes : ce qu’affichait chaque terminal annexe est écrit sur le disque pour revenir après une relance. Le désactiver efface les historiques enregistrés.

Tickets

Quand une nouvelle session désigne un ticket — dans son champ Ticket, son nom ou son prompt —, sa page s’ouvre dans la vue web et, avec Insérer le titre des tickets dans les notes, son titre est ajouté en haut des notes, dans le Format de la ligne de votre choix ({title}, {id}, {url}).

Un résolveur indique quelles adresses sont des tickets : GitHub, GitLab, les merge requests GitLab, Jira Cloud et Linear sont fournis. Ajoutez les vôtres pour un GitLab auto-hébergé, un Jira Server ou un Redmine : un nom, un motif d’adresse avec une capture nommée comme (?<number>[0-9]+), un identifiant comme #{number}, et des motifs de nettoyage du titre. Tester avec une adresse le vérifie. Les résolveurs peuvent être importés et exportés ; voir docs/ticket-resolvers.md.

Activité

Résumer automatiquement les sessions : après chaque tour, l’agent écrit un court résumé de la session avec son modèle le plus léger, au plus une fois toutes les cinq minutes ; il s’affiche dans l’inspecteur et Ouvrir rapidement y cherche. Il utilise le compte de votre agent.

Demandes

Deux pages, Signalement et Avatars.

Panneau flottant
Afficher les demandes au-dessus des autres applications active le panneau flottant. Choisissez son avatar (Gérer les avatars…), s’il masque ou garde l’avatar à l’écran Sans demande en attente, et Remettre à sa place s’il s’est perdu. Son raccourci est ⌃⌥⌘P.
Notifications
Me notifier des demandes, en montrant Le type de demande ou La commande ou la question. Indisponible tant que le panneau flottant est actif, puisqu’il les signale déjà.
Palette
Afficher le nombre de demandes sur l’icône du Dock ; déplier la palette à l’arrivée d’une demande.

Mises à jour

Rechercher automatiquement les mises à jour
Chaque jour, chaque semaine ou chaque mois.
Télécharger et installer automatiquement les mises à jour
Installe en arrière-plan ; sinon, la question vous est posée.
Canal
Stable, ou Instable pour recevoir aussi les versions candidates.
Rechercher maintenant
Aussi dans Vibe Manager › Rechercher les mises à jour….

Les mises à jour sont signées deux fois — avec le Developer ID de l’app et avec une clé EdDSA — et vérifiées avant d’être installées. Quand des agents tournent, la mise à jour pose la même question qu’en quittant : installer en les laissant tourner, ou tout arrêter.
