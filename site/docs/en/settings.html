Settings

Every page of Vibe Manager › Settings… (⌘,), and what each setting does. The sidebar groups them as System Settings does; the window widens by itself for the pages that need the room, such as the templates.

The General page, and the sidebar of every page.

General

Open sessions in
Conversation or Terminal, for sessions you have not switched yourself (⌥⌘T).
Ask before closing or archiving a session where work is running
On by default. Off, closing and archiving never ask.
When quitting with agents running
Ask, Keep them running or Stop them: see Quit without stopping the agents.
Summarize sessions automatically
After each turn, the agent writes a short summary of the session with its lightest model, at most once every five minutes, shown in the inspector and searched by Open Quickly. It uses your agent's account.
Keep the history of side terminals
What each side terminal showed is written to disk so it comes back after a relaunch. Turning it off erases the saved histories.
Open changed files with
What Return or a double-click does on a file of the inspector: Finder (reveal only), Default Application, one of the editors found on this Mac, or Other….

Conversation

Theme
See Themes and avatars.
Display
Accent colour, message font, code font, text size (Small to Extra Large), density (Compact or Comfortable), your messages as Bubbles or Lines.
Technical details
Group consecutive calls of the same kind; unfold a failed call; unfold file edits; show reasoning rows; wrap lines in code blocks; line numbers in diffs.

Badges

The symbols and colours offered for sessions' badges: see Badges.

Notifications

Floating Panel
Show requests above other applications turns on the floating panel. Choose its avatar, whether it hides or keeps the avatar on screen With no pending request, and Put Back in Place if it got lost. Its shortcut is ⌃⌥⌘P.
Notifications
Notify me of requests, showing The kind of request or The command or the question. Unavailable while the floating panel is on, which already signals them.
Palette
Show the number of requests on the Dock icon; unfold the palette when a request arrives.
Manage Avatars…
Opens the Avatars page, your avatar library: see Avatars. The ‹ button goes back to the notifications.

Agents

One page per agent: Claude Code, Codex. The dot in the sidebar says whether it is ready (green), usable with something to fix, too old or not signed in (orange), or not found (red). The page shows where its command-line tool was found and its version; Detect Again looks for it again, after an installation or an update.

Track … activity
For an agent that has its hooks approved, such as Codex. On, the hooks report when it works, asks or finishes, which the sidebar and the requests need. The first time, a sheet shows the commands the hooks run, and you approve them once. Claude Code has no such setting: its hooks need no approval.

Endpoints

Each model server you declared has its page, and the dot in the sidebar gives the result of its last test. Add an Endpoint… starts from Ollama, LM Studio, OpenRouter or an Other Server: a known server fills in the address, the key it expects and the protocol; only another server asks for its protocol. See docs/endpoints.md.

Web View

Give agents the web view
Starts each agent with the vibe-browser tool server. Takes effect at the next start of each agent.
Show the web view when an agent opens a page
Brings the web view forward when the agent opens a tab.
Open links
In the web view or In the default browser, for links ⌘-clicked in a terminal; ⌥ does the other.
Always allowed sites
The sites where you chose Always Allow; Remove takes one back.
Browsing data › Clear…
Erases the cookies and data of the web view, which signs you out of every site in every session.

Templates

The prompt template editor: see Prompt templates.

Tickets

When a new session names a ticket — in its Ticket field, its name or its prompt — its page is opened in the web view, and with Insert ticket titles in the notes its title is added at the top of the notes, in the Line format you choose ({title}, {id}, {url}).

The Resolvers line opens their page. A resolver says which addresses are tickets: GitHub, GitLab, GitLab merge requests, Jira Cloud and Linear are shipped. Add your own for a self-hosted GitLab, a Jira Server or a Redmine: a name, an address pattern with a named capture such as (?<number>[0-9]+), an identifier such as #{number}, and title cleanup patterns. Test with an address checks it. Resolvers can be imported and exported; see docs/ticket-resolvers.md.

Privacy

Whether Vibe Manager has Full Disk Access — Granted, Not granted, or Granted, not yet in effect — with Open System Settings. Agents inherit the access of the process that runs them, which may have started before you granted it: Restart When Idle lets it go once its last agent ends, Restart Now… stops the agents it names and resumes them. The Process by Process section appears when they disagree.

Data on This Mac › Track agent usage
Records running time and reads token counters for the Usage window. Clear Usage Data… erases what was recorded, not the agents' transcripts.
Data on This Mac › Diagnostics
Export Diagnostics…: see Troubleshooting.

Updates

Check for updates automatically
Daily, weekly or monthly.
Download and install updates automatically
Installs in the background; otherwise you are asked.
Channel
Stable, or Unstable to also receive release candidates.
Check Now
Also in Vibe Manager › Check for Updates….

Updates are signed twice — with the app's Developer ID and with an EdDSA key — and verified before they are installed. When agents are running, the update asks the same question as quitting: install and keep them running, or stop them all.
