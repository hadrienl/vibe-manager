The inspector

The column on the right holds the context of the session on screen: what it is about, what it changed, your notes, its agent and what it used.

Activity, Git and notes of a session.

Show or hide it with the toolbar button or View › Hide Context (⌥⌘I). Its header shows the session's badge and name: click them to change them. Each section folds, can be dragged to another place and resized; ⌥-click a header folds or unfolds them all, and View › Reset Column Layout puts everything back.

Activity

Summary
A few lines on where the session stands, written by the agent itself after its turns, with its lightest model, at most once every five minutes. It is turned on or off in Settings › Activity.
Resources
The tickets, pull and merge requests, branches and worktrees the session touched, found in its transcript. Right-click one to copy its address, reference or path, or reveal its repository.

Git

Every repository the session worked in, kept live while the session is on screen — including worktrees the agent created for itself. For each one:

  • the branch, how far it is ahead of or behind its upstream (as last fetched), and a merge or rebase left in progress;
  • the conflicted, staged, unstaged and untracked files, in Git's order;
  • the files already committed on the branch since origin/main, so that a session whose agent committed its work still shows what it changed.

Files are attributed to the agent that changed them: when two sessions share a folder, a file that is not in this session's transcript is flagged. Return or a double-click opens a file in the editor chosen in Settings › General; ⇧⌘R reveals it in the Finder; its context menu copies its path.

Vibe Manager only reads. It never creates a branch, stages, commits or fetches: the agent does what it needs, and the inspector reports it. Nothing polls on a timer either — a change on disk triggers one git status, without ever taking a lock.

Notes

Plain text, one note per session, typed right in the inspector: View › Edit Notes (⌥⌘N) jumps there, Esc goes back. Notes are saved a moment after you stop typing and whenever you leave the session; the header says when they are on disk. They survive closing, relaunching and archiving, and the sidebar search finds them.

When Settings › Tickets allows it, the title of a ticket you paste is inserted next to its link.

Agent, usage and initial prompt

Agent
The agent and model of the session, the history of its switches, and Switch…: see Switch agent or model.
Usage
The running time and runs of the session, and the tokens read from the agent's transcripts.
Initial prompt
The first message the session was created with, and the template and revision it came from.

The Usage window

Window › Usage (⌥⌘U) adds it all up over a period — today, 7 or 30 days, this month, the previous one, or all time — grouped by session, agent or model, as tokens or as running time.

What the agents used, by session, agent or model.

Running time is measured by the app, sleep excluded. Tokens are read from the counters in the transcripts Claude Code and Codex write, and marked ≈. No cost is shown: neither CLI reports one that holds together. Usage tracking can be turned off or cleared in Settings › General.
