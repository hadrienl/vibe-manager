Vibe Manager documentation

Vibe Manager is a native macOS app that runs several Claude Code and Codex sessions side by side, and keeps track of each one: its folder, its agent, its terminal, its notes and what it changed in Git.

The main window: the sessions, the session on screen, and its context.

The idea

A session is one task given to one coding agent in one working folder: “fix the cart VAT calculation” in storefront-web, with Claude Code. Vibe Manager launches the agent's own command-line tool, in a real terminal, and keeps everything around it:

  • the conversation, readable like a chat, or the raw terminal — one shortcut switches between them;
  • a status — To Do, In Progress, Waiting, Done — so the sidebar works as a task list;
  • the requests of the agents, answered from a palette without leaving what you are doing;
  • the Git changes of the session, live, and its notes;
  • side terminals and a web view the agent can drive.

Nothing is sent anywhere: there is no account, no telemetry, and the app never reads your API keys. The agents run with the permissions you gave their CLI, no more, no less.

The window

The sidebar, on the left
Your sessions, one column per status behind four tabs, with what each agent is doing: working, waiting for approval, a new reply. Below, the Pending Requests palette. At the foot, the archive, the sort order and the filters. See Organize your sessions.
The session, in the middle
The conversation with the agent or its terminal, the composer to write to it, and a status bar. See Conversation and terminal.
The inspector, on the right
The context of the session: its activity and summary, its Git changes, its notes, its agent, what it used. See The inspector.

The toolbar holds the Conversation | Terminal switch and three buttons: new session, web view, and inspector.
