Conversation and terminal

Every session runs its agent in a real terminal. The conversation view reads what the agent writes and shows it like a chat: messages in full, the rest folded under a title that says what it did.

Two views of the same session

The Conversation | Terminal switch in the toolbar, or View › Show Terminal (⌥⌘T), flips between them. Both stay live, so switching is instant and each keeps its place. Each session remembers the view you left it in; new sessions open in the one chosen in Settings › General.

The terminal is always the truth: the conversation is read from what the agent writes.

The terminal is the agent's own interface, untouched: everything you can do in claude or codex in a terminal, you can do here. The status bar below it shows whether the process runs, with Stop or Restart, and the button of the side terminals.

Reading a conversation

  • Messages — yours and the agent's — are shown in full, with Markdown, tables and code.
  • Tool calls are folded under a title: “2 files read”, “Searched for VAT_RATE”, “Run the test suite — 13 tests passed”. Consecutive calls of the same kind are grouped; the most serious state shows on the group. Click to unfold: a file edit shows its diff, a command its output.
  • Reasoning, when the agent shares it, is a folded row.
  • Sub-agents started by the agent appear as blocks with their mission, their activity and their result; a tray lists those still running.
  • Images the agent generates are shown in place.

When you scroll up, a new messages pill takes you back to the end. Edit › Copy as Markdown (⌥⇧⌘C) copies the selection with its formatting. How much is folded or unfolded is set in Settings › Conversation › Technical details.

The conversation is read from the transcript files Claude Code and Codex write, and kept in memory only. Vibe Manager never writes it anywhere, never logs it, never sends it. Links are only http, https and mailto, and no remote image is loaded.

Writing to the agent

The composer at the bottom writes into the agent's terminal as if you typed it.

  • Return sends, ⇧Return adds a line.
  • ↑ and ↓ on the first or last line recall the messages you sent before.
  • A message typed while the agent is working is sent when its turn ends.
  • Esc interrupts the agent, like the Stop pill that shows during a turn.
  • / at the start opens the list of the agent's skills and commands, as its CLI gives them. Typing filters it; ↑ ↓ choose, ⇥ or a click inserts, Esc closes. Return completes a name you started, and sends a name typed in full as it is. A command that answers with a panel, such as /mcp or /model, shows the real terminal above the composer while you use it.
  • A message starting with ! is a shell command, run by the agent's own shell mode; the composer turns to the warning colour. Type \! to send a message that starts with an exclamation mark.

While the agent waits for an answer in its terminal — a permission, a question — the composer is closed, and the request is shown instead: see Answer your agents.

Attaching files

Drop files on the conversation, click + in the composer, or choose Session › Attach Files… (⌘O): they become chips in the composer and are sent as paths with your message. Dropped on the terminal, a file's path is typed, escaped as Terminal does, without pressing Return. You can also drop files on a session's row in the sidebar.

A sent message keeps its attachments under its text: an image's thumbnail, a PDF's first page, a text file's first lines, a small player for a sound. A click opens them in Quick Look (← → go from one to the next); a right-click offers Open, Show in Finder, Copy and Open in Web View. A program or a script is never opened from here.
