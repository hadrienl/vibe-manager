Organize your sessions

The sidebar is a task list: four columns of status, groups by project, a manual order, filters, and an archive where nothing is ever deleted.

The In Progress column, and the requests waiting below.

Four statuses

Each session is To Do, In Progress, Waiting or Done, one column per status behind the four tabs at the top of the sidebar. The count shows on each tab, and an orange dot marks a column where a session waits for you.

The status says where the work stands, not what the agent is doing: a session you close stays in its column, and only starting or restarting one brings it back to In Progress — or ⌘Z taking back a status changed from the keyboard, which restarts nothing. To change it:

  • swipe a row sideways with two fingers: the statuses before and after its own appear, click one;
  • use Session › Status or the row's context menu;
  • press ⌃⌘→ or ⌃⌘← to move to the next or previous status; ⌘Z, with the keyboard in the sidebar or the inspector, takes the move back.

⌥⌘→ and ⌥⌘← switch columns.

What a row tells you

Each row shows the session's badge, name and agent, and what the agent is doing right now:

StateMeaning
WorkingThe agent is taking its turn.
Needs approvalIt asks permission to run a command or edit a file.
Has a questionIt asks you something.
New replyIt finished its turn since you last looked.
IdleIt waits for your next message.
Finished, Failed, Exited with code…The agent's process ended.
ClosedThe session is closed; everything it carries is kept.

A hand on the row means the agent waits for your approval in the web view, a globe that it opened a page. The first nine sessions of the column answer ⌘1 to ⌘9; ⌥⌘↑ and ⌥⌘↓ go to the previous and next session.

The working, question and finished states come from the agent's own hooks, which you approve once per agent: see Settings › Agents.

Group by project

View › Group Sessions by Folder (⌃⌘G), or the folder button at the foot of the sidebar, gives each working folder a foldable section. Its header shows how many sessions it holds and the most pressing of their states.

Sessions grouped by working folder.

Right-click a header to rename the group (or go back to the folder's name), start a New Session in This Folder, move the group, or reveal the folder in the Finder. ⌃⌥⌘← and ⌃⌥⌘→ fold and unfold the current group.

Sort, filter, search

The menu at the foot of the sidebar sorts by Last Activity, Date Created, Name or Manual. In Manual, drag a row anywhere in its column (or its group), and drag a group header to move the whole group; ⌃⌘↑ and ⌃⌘↓ do the same from the keyboard. A new session arrives at the top, and a session keeps its place when it restarts or changes column.

The same menu filters by agent or by folder; a filter icon shows while one is on. The search field at the top searches the sessions' names, first prompts, notes, templates and folders, ignoring case and accents.

Open Quickly

File › Open Quickly… (⌘P) finds a session from whatever you have at hand: a ticket number (142, #142, owner/repo#142, !87), the URL of a ticket, pull request or merge request pasted as is, a branch, a worktree, a folder, or words of its title, summary or notes. Each result says why it matches; Return brings the session on screen, archived ones included.

Close, archive, restart

Close Session ⇧⌘W
Stops the agent and keeps everything: the conversation, the terminal output, the notes. The session stays in its column, and a bar offers to restart it. ⌘W never closes a session: it closes the web view tab or the side terminal that has the keyboard.
Restart Session ⌃⌘R
Puts a closed session back to work. When the agent can resume its own conversation, it does, and nothing is sent. When it cannot, the app says so and offers a new process with a summary of the session, which you can read and edit before it is sent. Same agent, model, folder and worktree.
Archive ⌃⌘A
Takes the session out of the columns. Nothing is deleted: Archived at the foot of the sidebar (or ⌥⌘A) lists the archived sessions, and Unarchive (⇧⌃⌘A) brings one back.

Closing and archiving ask first only while something runs in the session — its agent, or a command in a side terminal — so you can press ⌃⌘A again and again to empty a column. Select several rows with ⌘-click or ⇧-click to close, archive, restart or move them together.
