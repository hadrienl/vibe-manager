Create a session

A new session starts as a draft in the main area. Nothing runs until you send it.

Open a draft

Press ⌘N, choose File › New Session, or click + in the toolbar. The draft appears at the top of the sidebar and fills the middle of the window. To start in a folder you already use, right-click a group header in the grouped sidebar and choose New Session in This Folder.

A draft: options on top, the first message at the bottom.

The options

Badge and title
The badge on the left of the title opens a picker of symbols and colours; a session in a folder with an app icon, a favicon or a logo wears it by default. The title is optional: left empty, it is derived from the first message when you send.
Prompt template
None — free prompt, or one of your prompt templates. A template can propose the folder, the name and the badge; its fields appear right below.
Working folder
The folder the agent works in. Your recent folders are offered as cards (the three latest, then Show More); right-click one to remove it from the list or show it in the Finder. Choose… opens any other folder. The agent is started in that folder; it may create branches and worktrees on its own, and the inspector reports them.
Agent
One card per agent found on this Mac, with its state. An agent that is missing, too old or signed out says so; fix it and click Detect again.
Model
Default model of the agent, or one of the models the agent's CLI lists. Leave the default to use what you configured in the CLI.
More Options › Ticket
Optional: a ticket URL or a number such as #142. It names the session's ticket, opens it in the web view, and lets Open Quickly find the session by it. Left empty, a branch named after a ticket fills it in later.

The first message

Describe the task in the composer at the bottom: it is the agent's first message. With a template, the composer shows the prompt exactly as the agent will receive it; Edit as Text lets you change it by hand.

  • Return or the arrow button creates and launches the session (⌘Return works from anywhere in the draft).
  • ⇧Return adds a new line.
  • ⌥Return or Add to To Do creates the session without starting it: it waits in the To Do column until you start it with Session › Start Session (⌃⌘R).
  • Esc or Discard throws the draft away; ⌘Z brings it back.

Drop files anywhere on the draft, or click +, to attach them to the first message.

Without a prompt, the agent starts with nothing to do: useful to open a CLI in a folder and type to it yourself.

Rename and change the icon

A session's name and badge can change at any time: Session › Rename… (⌃⌘E) or a double-click on its row, and Session › Change Icon… (⌃⌘I) or a double-click on its badge. ⌘Z undoes either. The symbols and colours on offer are set in Settings › Badges.

What happens when you send

The session is saved first, then shown, then its agent is launched in a terminal of its own. If the launch fails, the session is kept with everything you typed, and Restart tries again. The session moves to In Progress, and the agent's activity shows on its row from then on.
