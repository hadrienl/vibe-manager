Keyboard shortcuts

Every command of Vibe Manager is in a menu, and most have a shortcut. The keyboard reaches everything, and VoiceOver reads it all.

Sessions

ShortcutCommand
⌘NNew Session
⇧⌘NNew Session from the first template
⌘POpen Quickly
⌘1 … ⌘9Go to the first nine sessions of the column
⌥⌘↓ ⌥⌘↑Next, previous session
⌃⌘RRestart Session (or Start Session)
⌃⌘MSwitch Agent…
⌃⌘ERename…
⌃⌘IChange Icon…
⌘OAttach Files…
⌃⌘→ ⌃⌘←Move to the next, previous status
⇧⌘WClose Session
⌃⌘AArchive
⇧⌃⌘AUnarchive

Sidebar

ShortcutCommand
⌥⌘→ ⌥⌘←Next, previous column
⌃⌘↑ ⌃⌘↓Move the session up, down (Manual sort)
⌃⌘GGroup Sessions by Folder
⌃⌥⌘← ⌃⌥⌘→Collapse, expand the group
⌥⌘AShow Archived Sessions
↑ ↓, ReturnWalk the list, give the keyboard to the session
⌘-click, ⇧-clickSelect several sessions
⌘Z ⇧⌘ZUndo, redo a rename or an icon change

View and focus

ShortcutCommand
⌥⌘TShow Terminal / Show Conversation
⌥⌘IShow / Hide Context (the inspector)
⌥⌘BShow / Hide Web View
⌘JShow / Hide Terminals (the side drawer)
⌘TNew Terminal
⌥⌘NEdit Notes
⌥⌘1 … ⌥⌘5Focus the sidebar, the session, the inspector, the web view, the side terminals
⌥⌘PFocus Pending Requests
⌃⌥⌘PLend the keyboard to the floating panel, from any app
⌥⌘UUsage window
⌥⇧⌘CCopy as Markdown
⌃⌥⌘ORead Last Output (VoiceOver reads the terminal's last lines)
⌘WClose the web view tab or side terminal that has the keyboard — never the session

Composer and draft

ShortcutCommand
ReturnSend; in a draft, create and launch
⇧ReturnNew line
⌘ReturnCreate and launch, from anywhere in the draft
⌥ReturnAdd to To Do, without launching
↑ ↓Recall the messages you sent
EscCancel a recall, leave shell mode, then interrupt the agent; in a draft, set it aside
! at the startRun a shell command through the agent

Web view

ShortcutCommand
⌘LOpen Location…
⌘RReload Page
⌘[ ⌘]Back, Forward
⌃⇥ ⌃⇧⇥Next, previous tab (also in the side terminals)

Inspector and requests

ShortcutCommand
⌥⌘↑ ⌥⌘↓Move an inspector section (its header focused)
⌥-click a headerFold or unfold every section
Return, double-clickOpen the file in your editor
⇧⌘RReveal the file in the Finder
⌘ReturnOpen the request's session (palette, floating panel)
