Prompt templates

A prompt template is a prompt with fields — Review {{url}} — ready to start a session from: a form, an exact preview, and a session named after what you typed.

Start a session from a template

Pick a template at the top of the New Session draft, or go straight to File › New Session from; ⇧⌘N opens the first one. Each field becomes a control; a required one keeps the session from being created until it is filled. The composer previews the prompt exactly as the agent will receive it.

The template proposes the folder, the name and the badge; the composer shows the exact prompt.

The session keeps the rendered text, with the template's name and revision: changing the template later changes nothing already created, not even what Restart sends.

Write a template

Templates are edited in Settings › Templates, also reached with File › Manage Prompt Templates….

The template editor, with a value to try per field.
What is it for?
The template's name, as listed in menus.
Session name
Optional, with the same fields: Review !{{url|/merge_requests\/(\d+)/}}. It names the session until you type a name of your own.
Folder
Optional: the working folder proposed with the template. Written with ~, it means the same folder on another Mac.
Appearance
Optional: the symbol and colour given to its sessions.
Prompt
The text, with its fields. The table below it sets each field's label, hint, whether it is required and whether it takes several lines.

The Try it column takes a value per field and shows what each pattern keeps of it; the preview below uses the same values. Save or Revert when you are done. The ⋯ menu duplicates, moves, deletes, imports and exports templates, and Add Examples adds a few to start from.

Syntax

WrittenMeans
{{url}}A required field named url. {{ url }} and {{URL}} are the same field.
{{focus?}}An optional field. Left empty, it adds nothing.
{{url|/merge_requests\/(\d+)/}}Only part of the value: what the regular expression finds, or its first group — 1315 out of …/merge_requests/1315/diffs.
\{{Two literal braces: \{{url}} is the text {{url}}.

A field name starts with a letter and holds letters, digits, - and _. Anything else between double braces — {{payload.url}}, {{#each}} — stays text, since prompts are full of code using the same braces; the editor underlines it. The same field used twice is asked once. A template has at most 20 fields and 16 KB of text.

A pattern that finds nothing adds nothing: the form says so under the field, and the session can still be created. {{url|/(?:merge_requests|pull)\/(\d+)/}} gives the number of a GitLab merge request or a GitHub pull request alike.

What the agent receives

  • A value is inserted as typed, and never read again: a value holding {{x}} stays that text.
  • Nothing is quoted: the prompt reaches the agent as a single argument, with no shell in between, so $, quotes and backticks arrive untouched.
  • A one-line field loses its surrounding spaces; control characters pasted from a coloured terminal are removed.

Share templates

Export… writes a JSON file; Import…, or dropping a file on the window, reads one and shows first which templates are new, identical or changed. A changed template is kept beside yours unless you choose Replace. The file format is documented in docs/prompt-templates.md.
