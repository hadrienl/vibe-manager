Install Vibe Manager

Download the disk image, drag the app to Applications, and make sure at least one agent is installed and signed in.

Requirements

  • macOS 14 Sonoma or later, on Apple silicon or Intel.
  • At least one coding agent, installed and signed in:
    AgentCommandMinimum versionSign in with
    Claude Codeclaude2.1.0claude auth login
    Codex CLIcodex0.153.0codex login

Vibe Manager uses your agents as they are, with your own account and quota. It never asks for an API key.

Download and install

  1. Download the latest .dmg from the home page or from GitHub Releases.
  2. Open it and drag Vibe Manager into Applications.
  3. Launch it from Applications. The app is signed with a Developer ID and notarized by Apple, so macOS opens it without a warning.

Updates are then offered by the app itself: see Settings › Updates.

How agents are found

At launch, and whenever you click Detect again, Vibe Manager looks for claude and codex in the usual places — /opt/homebrew/bin, /usr/local/bin, ~/.local/bin, ~/.bun/bin, ~/.npm-global/bin, ~/.volta/bin, the asdf and mise shims, ~/.claude/local, ~/.codex/bin… — then in your PATH, and last in your login shell's PATH. A native build is preferred over one that runs under Rosetta.

When an agent cannot be used, the New Session form says why: not installed, not executable, too old, or not signed in. Fix it in a terminal, then click Detect again.

Full Disk Access

Agents run as children of Vibe Manager, so when one of them reads a protected folder — Documents, Desktop, Downloads, iCloud Drive — macOS asks Vibe Manager for permission. To avoid a string of prompts in the middle of your work, the app offers once, at the first launch, to grant Full Disk Access:

The one-time Full Disk Access step.
  1. Click Open System Settings: Privacy & Security › Full Disk Access opens.
  2. Turn Vibe Manager on.
  3. Come back to Vibe Manager.

Not Now is a perfectly good answer: repositories rarely live in protected folders, and nothing is disabled. You can grant it later from Settings › Privacy, which also shows whether the processes that run your agents already have it.

Agents keep the access they had when they started. If you grant Full Disk Access while agents are running, Settings › Privacy offers Restart When Idle or Restart Now… so they pick it up.

Your first session

On the first launch, bubbles guide you on the interface itself, from the New Session button to the agent started and its session's status. Skip Tutorial dismisses them; Settings › General › Tutorial brings them back.

Press ⌘N, choose a working folder, check the agent, describe the task and press Return. The next page explains every option: Create a session.
